Front end for the plant leaf disease detector. Supports tomato, potato and bell pepper leaves only. `SPACE` is set to `zia2/plant-leaf-disease`. Edit it at the top of the script in `index.html`
to point at the Gradio Space that serves the model. Add `?demo=ok`, `?demo=healthy` or `?demo=low` to the URL
for an offline preview that does not call the model.
